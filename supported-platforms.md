# Supported platforms for the initial Trial release

The separately supplied AEGIS Trial Core wheel is currently supported only on:

- Linux x86_64
- CPython 3.11

The public SDK exposes integration APIs for PyTorch, Hugging Face Trainer, and
torch distributed. Those APIs are not a claim that every architecture, accelerator,
or distributed topology is validated for the Trial Core. Use the configuration
provided with your trial materials.
